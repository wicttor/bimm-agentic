# Context builder with token budget

## Goal
Pass the right slice of context per step without exceeding token limits. The builder assembles contract files plus only the current task's dependency outputs, eliding lowest-priority content until under budget — while never dropping the spec or the hard rules.

## Acceptance Criterion
For a given task the builder assembles the contract files plus only that task's dependency outputs, elides lowest-priority content until under a configured token budget, and never drops the spec or the hard rules, reporting what it omitted.

Run and confirm failure (context builder doesn't exist yet).
2. **Green — Implement:** create `agent/src/context.ts` with a `buildContext(task, planState, budget)` function that: loads contract files, loads dependency outputs, calculates token count, elides lowest-priority sections until under budget, returns the assembled context plus an `omitted` report.
3. **Refactor:** ensure the priority ordering for elision is clear and configurable; verify the `omitted` report is structured and actionable.
