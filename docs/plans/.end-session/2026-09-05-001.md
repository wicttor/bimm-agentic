# Session End: Add OpenRouter provider and strengthen planner prompt

## Reason

Implemented two improvements to address LLM integration issues:

1. **Strengthened Planner Prompt** — User was getting "Expected an array of tasks, but got object" validation error. LLM was wrapping results in `{tasks: [...]}` instead of bare arrays. Enhanced prompt with:
   - CRITICAL section emphasizing bare array output only
   - Explicit WRONG vs RIGHT examples with JSON delimiters
   - Reworded user instruction to emphasize starting with `[` and ending with `]`

2. **Added OpenRouter Provider** — OpenAI was experiencing persistent failures. OpenRouter provides access to 200+ models (Claude, Llama, Mistral, etc.) through a single API with better pricing and reliability. Integrated seamlessly with existing provider system.
