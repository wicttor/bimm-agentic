## Learnings to Capture

Candidates for `/learn`:

1. **Sentinel stubs keep the Red gate at assertion level** (extends the existing pattern learning):
   the missing-source block is the natural extension of the Red-gate discipline into refusal paths,
   where a stub returning `ok: false, reason: "missing-source"` lets the test fail on its
   `expect(failure.reason).toBe("missing-source")` assertion rather than on `Cannot find module`.
2. **Mutation tests must back up outside `/tmp` when one mutation deletes its own fixture root**:
   `dirname(fixtureRoot)` was the output, and a broken guard turned that into `rmSync("/tmp")`. The
   learned rule: store mutation-run state in `~` or `/var/tmp`, not in the same shared directory the
   mutated code can reach.
3. **Mutation tests against the real reference tree leave artifacts** (gotcha): M8 wrote
   `src/.scaffolded` during every mutation pass. The test-side fix is the whole-tree hash snapshot;
   the operational fix is `rm -f src/.scaffolded` before each commit.
4. **A whole-tree hash snapshot is the read-only assertion that beats a two-byte comparison**:
   `expect(readFileSync(...)).equals(before)` proves the *compared files* are untouched, but a
   scaffold can write a *new* file into `src/` without changing the compared files. `treeSnapshot`
   makes the assertion catch that class of bug.
5. **Nested fixture roots make destructive tests safe** (workflow): `makeFixtureRoot` returns
   `join(mkdtemp, "repo")` instead of `mkdtemp()` itself, so any `dirname(root)`-based test has a
   private disposable ancestor even when its guards are broken by a mutation.
6. **Refuse an output at/below a copied source path** (decision, pattern): the AC says
   "refuses a non-empty output without `--force`", but the hard invariant ("reference `src/` is
   never written to") requires refusing an output that *would* `rm -rf` reference content under
   `--force`. The test for it is the one that catches the M5 mutation.

## Learning Gaps (carried forward, augmented)

- **No established pattern for cross-test fixture trees in this repo.** `treeSnapshot` was invented
  in T04 — if T05 (sandboxed tool registry) and T11 (repair loop) need the same whole-tree
