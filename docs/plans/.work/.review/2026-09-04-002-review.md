## Learnings to Capture (hand to `/learn`)

1. **Agent tests are typechecked — casts in tests can break sibling suites** — gotcha ·
   typescript/testing · source: T02 / Green. `agent/tsconfig.json` includes `agent/tests/**`, so a
   loose `as { config: Record<string, unknown> }` cast in `config.test.ts` failed
   `agent:typecheck` — which in turn failed **T01's wiring test** ("baseline agent:typecheck must
   pass"). Type errors are cross-cutting in this repo: narrow discriminated unions
   (`if (!result.ok) throw`) instead of casting.
2. **`--dry-run` proves zero-network via two spies** — pattern · testing/agent-runtime ·
   source: T02 / Green + Red. Asserting "zero HTTP calls" needs an *architecture* that makes it
   possible: a `createProvider` injection seam (spy counts instantiations) + a global fetch
   replacement (spy counts requests). The real `FakeProvider` stayed in T03's lane.
3. **Explicit provider + its missing key = fail, never fall back** — decision · config contract ·
   source: T02 / Green (caught mid-Green). `LLM_PROVIDER=anthropic` with only `OPENAI_API_KEY` set
   must exit naming `ANTHROPIC_API_KEY`; silently switching providers was rejected. The initial
   test expectation encoded the wrong rule and was corrected against the AC, not the implementation.
4. **Spawn the real entry to prove CLI-runnability** — workflow · testing · source: T02 / Green.
   Node ≥ 23.6 type-strips, so `execFileSync("node", ["agent/src/index.ts", ...])` with a scrubbed
   env (`PATH` only) tests the actual `process.exitCode` contract without adding `tsx` or npm
   scripts; pair it with an `isDirectExecution()` guard so importing `run()` in vitest never
   auto-executes main.
